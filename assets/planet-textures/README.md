# Planet surface textures

The three JPG maps in this folder are unchanged copies of `2k_earth_daymap.jpg`, `2k_jupiter.jpg`, and `2k_sun.jpg` from [stirlo/oursquadis.top](https://github.com/stirlo/oursquadis.top/tree/37e9ccce2d7eeaecae8893e20dd2d201fe12ab30) at commit `37e9ccce2d7eeaecae8893e20dd2d201fe12ab30`.

That project's README credits NASA public-domain imagery for the planet textures. Its Mozilla Public License 2.0 text is included as `LICENSE` in this directory. The files are served from this site so the desktop and mobile renderers use the same maps without a third-party CDN dependency.
