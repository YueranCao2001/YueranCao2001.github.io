01 / Overview

The research question

Surgical video × Vision–language

SurgClip investigates how lightweight domain adaptation improves matching between surgical keyframes and phase descriptions, examining the adaptability of general-purpose vision–language models within a clearly defined evaluation scope.

Surgical phases share instruments, anatomy and actions, making subtle visual distinctions difficult to match with text. SurgClip trains a lightweight phase adapter on CLIP features, using the baseline model to test whether domain information improves alignment between keyframes and phase descriptions.

My work spans video frame extraction, annotation indexing, adapter training, retrieval evaluation and visualization. Separate comparisons of domain adaptation, INT8 quantization and PQ embedding compression measure matching quality, adapter file size, embedding storage and runtime costs, tying each conclusion to its experimental setting.

Measuring adaptation gains

Compare keyframe–text rankings from baseline and phase-adapted CLIP, using aggregate metrics and phase-level results to assess adaptation within the stated evaluation scope.

Evaluating compression and runtime

Examine adapter file size, embedding storage, matching quality and latency separately, rather than assuming a smaller model file makes the system faster.

02 / Approach

From features to retrieval

From video data to measurable retrieval results

  1. 01

    Build the frame and phase index

    Extract frames from Cholec80 videos and associate them with phase annotations, organizing an index for training, feature extraction and evaluation to provide a consistent data basis for model comparisons.

  2. 02

    Adapt CLIP with a lightweight module

    Train a lightweight phase adapter on image and text encoder features, then use normalized representations and cosine similarity for matching. Compare the resulting rankings with baseline CLIP to assess the effect of domain adaptation.

  3. 03

    Evaluate, compress and visualize

    Compare Top-1 / Top-5 accuracy and phase-level performance, using examples and visualization to interpret the results. Evaluate INT8 adapters and PQ feature compression separately, recording matching quality, storage and runtime costs.

03 / Experiments

Results & trade-offs

Accuracy, storage and runtime

In the 184,578-frame full-index evaluation, which includes training data, phase adaptation raised Top-1 from 17.77% to 51.55% and Top-5 from 83.96% to 96.18%.

These are full-index results recorded in the repository. Each frame is matched against seven candidate phase texts. Top-1 and Top-5 indicate whether the correct phase appears in the first one or five results.

Evaluation context

Evaluation uses the full frame index, including training data, so these are not held-out generalization results. PQ figures estimate embedding storage rather than total system memory.

Compression does not guarantee faster inference.

In the recorded CPU benchmark, adapter-only latency increases from 0.0474 ms in FP32 to 0.1605 ms in INT8. This experiment demonstrates a trade-off between file size and runtime cost.

Existing shift checks and next validation

The repository already records preliminary brightness-and-blur shift results. Next, evaluate on a video-disjoint test set, standardize evaluation and timing protocols, and reassess stability on a consistent sample and model pipeline.
