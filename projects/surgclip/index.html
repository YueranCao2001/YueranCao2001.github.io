01 / Overview

从问题出发

手术视频 × 视觉语言

SurgClip 研究轻量领域适配如何改善手术关键帧与阶段文本的匹配，在明确的评估范围内分析通用视觉语言模型的适应能力。

手术阶段之间共享器械、组织与动作，细微的视觉差异增加了文本匹配的难度。SurgClip 在 CLIP 特征之上训练轻量阶段适配器，以基础模型为对照，检验领域信息能否改善关键帧与阶段描述的对应关系。

我的工作覆盖视频抽帧、标注索引、适配器训练、检索评估与结果可视化。领域适配、INT8 量化和 PQ 向量压缩采用独立对照，分别衡量匹配质量、适配器文件体积、向量存储与运行代价，使每项结论对应其具体实验设置。

量化领域适配收益

对照基础 CLIP 与阶段适配模型的关键帧—文本排序，结合总体指标与阶段表现分析适配效果，将结论与具体评估范围对应起来。

评估压缩与运行代价

分别考察适配器文件体积、向量存储、匹配效果与运行延迟，避免将更小的模型文件直接等同于更快的系统。

02 / Approach

从表示到检索

从视频数据到可量化的检索结果

  1. 01

    构建关键帧与阶段索引

    从 Cholec80 视频提取帧并对应阶段标注，组织为训练、特征提取与评估使用的数据索引，为后续模型比较建立一致的数据基础。

  2. 02

    用轻量适配器调整 CLIP 表示

    基于图像与文本编码器的特征训练轻量阶段适配器，通过归一化表示与余弦相似度完成匹配，并与基础 CLIP 比较领域适配前后的排序表现。

  3. 03

    评估、压缩与可视化

    比较 Top-1 / Top-5 命中率与不同阶段的表现，结合样例和可视化解释结果；进一步检验 INT8 适配器与 PQ 特征压缩，分别记录效果、存储和运行开销。

03 / Experiments

结果与取舍

准确率、体积与运行开销

在包含训练数据的 184,578 帧全量评估中，阶段适配后 Top-1 从 17.77% 提升至 51.55%，Top-5 从 83.96% 提升至 96.18%。

如何理解这些结果

当前评估使用全量帧索引，包含训练所用数据，不能视为独立测试集的泛化结果。PQ 数字是向量表示的存储估计，不等同于整个系统的内存占用。

压缩不自动等于加速。

在仓库记录的 CPU 基准中，适配器单独运行的延迟从 FP32 的 0.0474 ms 增至 INT8 的 0.1605 ms。因此，本次 INT8 实验体现的是体积收益与运行开销之间的取舍。

已有扰动检查与下一步验证

仓库已记录亮度与模糊扰动下的初步结果。下一步是按视频划分独立测试集，统一评估与计时口径，并在一致的样本和模型流程下复核稳定性。
